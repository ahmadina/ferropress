# Ferropress Roadmap

Each step is one self-contained unit of work: it ships with its own tests, passes the full quality gate
(format, lint, tests, coverage), and is committed and pushed before the next step starts. Later phases are
broken into numbered steps when they begin, using what earlier phases proved.

Status legend: `[x]` done · `[ ]` not started

## Phase 0 — Foundations

- [x] 1. Cargo workspace: root manifest with workspace lints, pinned toolchain, `rustfmt.toml`,
      `clippy.toml`, `.cargo/config.toml`
- [x] 2. `xtask check-layers`: fail when a crate dependency breaks the layer rules
- [x] 3. `deny.toml`: GPL-compatible license allow-list, advisories, banned crates
- [x] 4. CI workflow: fmt, clippy, tests, docs, coverage gates, `cargo deny`, forbidden-PHP-binary scan
- [x] 5. Architecture decision records (one commit each):
  - [x] ADR-0001 PHP engine: independent, clean-room Rust implementation
  - [x] ADR-0002 License and dependency policy (GPL-2.0-or-later)
  - [x] ADR-0003 Bridge semantics: PHP values and callables across the Rust boundary
  - [x] ADR-0004 Database parity
  - [x] ADR-0005 Worker and tenant isolation
  - [x] ADR-0006 Admin application and block-editor hosting
- [x] 6. `contracts/reference-manifest.toml` with pinned versions and hashes; `xtask verify-manifest`

## Phase 1 — Reference lab (oracle)

- [x] 7. `lab/` Docker stack: pinned upstream reference platform + PHP 8.5 + MySQL; `xtask lab up|down|reset`
- [x] 8. `xtask lab fetch`: clone upstream sources at pinned tags into git-ignored directories
- [x] 9. Capture tooling: HTTP responses, ordered hook trace, SQL log, DB diff, emails, cron events
- [x] 10. `test-harness` crate: scenario schema, comparators, reviewed normalizations, fakes
- [x] 11. `xtask lab check`: deterministic lab (fixed clock and secret keys); every scenario must give
      identical results in two runs from a fresh install

## Phase 2 — Contract inventory

- [x] 12. Symbol inventory into `contracts/inventory/`: functions, classes, hooks, constants, globals,
      REST routes, options, tables (recorded facts only; per-item descriptions in our own words follow
      with step 14)
- [x] 13. Lifecycle trace: boot, plugin load and hook order for single site and multisite
      (`contracts/lifecycle/`, recorded by `xtask lab lifecycle` from both lab profiles)
- [x] 14. Completeness dashboard: documented / implemented / tested / certified per item
      (`docs/COMPLETENESS.md`, generated by `xtask dashboard` from `contracts/entries/`; certified
      becomes measurable with step 22)

## Phase 3 — PHP engine in Rust (runs in parallel with Phase 2)

- [x] 15. `php-serialize`: byte-exact serialize/unserialize with property tests and fuzzing
- [x] 16. `php-value`: value model (ordered arrays, references, copy-on-write, object handles)
- [x] 17. Lexer → parser → bytecode compiler → VM core (one step each), checked against the PHP test suite
  - [x] Lexer: `php-lexer`, byte-exact tokens, lines and scanner diagnostics (`contracts/lexer/`,
        recorded by `xtask lab lexer`; `xtask lab lexer-corpus` matches every upstream source file)
  - [x] Parser: `php-parser`, syntax tree with the reference's errors, warnings and `assert()`
        rendering (`contracts/parser/`, recorded by `xtask lab parser`; `xtask lab parser-corpus`
        matches every upstream source file)
  - [x] Compile-time checks: `php-compiler` reports the reference's fatal errors, warnings and
        deprecations on their lines (`contracts/compiler/`, recorded by `xtask lab compiler`;
        `xtask lab compiler-corpus` matches every upstream source file except those listed as
        awaiting class linking, step 18, or built-in function descriptions, step 19)
  - [x] Bytecode compiler: code objects, instructions and a disassembler (ADR-0007)
  - [x] VM core: runs compiled units with the reference's output and errors (`contracts/vm/`,
        recorded by `xtask lab vm`; `xtask lab vm-phpt` reports how many upstream tests pass,
        fail or use constructs not compiled yet)
- [x] 18. Language features: functions and closures; classes, interfaces, traits, enums; exceptions;
      generators and fibers; include/require and autoloading
  - [x] Closures and arrow functions, including `use` captures and computed callees
  - [x] Classes: public instance properties, methods, `new` and `$this`
  - [x] Interfaces, traits and enums
  - [x] Exceptions: `throw`, `try`/`catch`, built-in `Exception`/`Error`
  - [x] `finally`
  - [x] Generators
  - [x] Fibers
  - [x] include/require and their `_once` forms
  - [x] Autoloading
  - [x] `foreach` over arrays and object properties
- [ ] 19. Built-in function families: strings, arrays, math, JSON, PCRE, mbstring, date/time, streams,
      mysqli/PDO, and the rest required by the certified plugin set
  - [x] Core strings, types, `count`, `function_exists`, `class_exists`
  - [x] Math: `abs`, `min`/`max`, rounding, `intval`/`floatval`/`strval`, `intdiv`, `sqrt`
  - [x] Array literals, `count` of arrays, `implode`/`join`, `explode`
  - [x] Array offsets: `$a[$k]`, `$a[$k] =`, `$a[] =`
  - [x] More arrays: `array_key_exists`, `in_array`, `array_merge`, `array_keys`/`array_values`
  - [x] More strings: `substr`, `strpos`, `str_contains`, `trim`/`ltrim`/`rtrim`
  - [x] mbstring: `mb_strlen` / `mb_substr` (UTF-8)
  - [x] Date/time: `gmdate`, `date`, `time` and `strtotime` for civil UTC timestamps
  - [x] Streams: `file_exists`, `file_get_contents`, `file_put_contents`, `is_file`, `is_dir`
  - [x] Paths: `dirname` and `basename` for `/`-separated paths
  - [x] JSON: `json_encode` / `json_decode` for scalars and arrays
  - [x] `isset` and `empty` of variables, offsets and expressions
  - [x] More strings: `str_replace` and `htmlspecialchars`
  - [x] `sprintf` for `%s`, `%d`, `%u`, `%x`, `%X` and `%f`
  - [x] `serialize` / `unserialize` for scalars, arrays and objects
  - [x] PCRE: `preg_match` and `preg_replace` for delimited patterns, including matches and a replace limit
  - [x] Constants: `define`, `defined`, `constant`, and bare constant names
- [x] 20. Bridge proof: Rust calls PHP closures with correct references, identity and reentrancy; PHP
      classes extend Rust-owned classes
  - [x] `php-value` invoke port (ADR-0003)
  - [x] `php-abi-bridge` calls PHP functions and closures from Rust
  - [x] By-reference arguments and object identity survive a round trip
  - [x] Reentrant core → PHP → core calls
  - [x] PHP classes extend Rust-owned classes
