# ADR-0009: PCRE2 for `preg_*`

- **Status:** Accepted
- **Date:** 2026-10-29

## Context

Roadmap step 19 requires the PCRE built-in family (`preg_match`, `preg_replace`, and the rest). Existing
plugins pass PHP patterns with delimiters and modifiers and expect PCRE2's dialect, backtracking and
error text. The Rust `regex` crate, `fancy-regex` and other engines implement different languages; using
them would pass simple cases and fail real plugin patterns. Embedding Zend or `libphp` for regex is
forbidden.

`unsafe_code` stays denied in `php-vm` (ADR-0008). The established `pcre2` crate (MIT, with `pcre2-sys`
vendoring or linking the PCRE2 C library under BSD-3-Clause) exposes a safe API over that engine.

## Decision

1. **Engine.** `preg_*` is implemented with PCRE2 through the `pcre2` crate's safe `bytes` API. Ferropress
   does not write its own regex engine and does not call Zend.
2. **Where.** The binding lives in `php-vm`. No new workspace crate and no `unsafe` in Ferropress code.
3. **Patterns.** PHP delimiter and modifier syntax is parsed in Rust and compiled as a PCRE2 pattern.
   Modifiers the crate cannot express (`D` dollar-endonly, and any later flag without a safe mapping) are
   reported as unsupported rather than silently ignored. `S` is accepted and has no match-time effect, as
   in the reference.
4. **License.** The wrapper is used under MIT. Vendored PCRE2 remains BSD-3-Clause. Both are on the
   ADR-0002 allow-list.

## Consequences

- Builds need a C compiler when `pcre2-sys` compiles PCRE2 from source (the default when no system
  library is found). CI already has that on Ubuntu and macOS.
- JIT is optional and off by default so compile errors stay deterministic in tests.
- A later ADR is required before `php-vm` may contain `unsafe` or before a dedicated `php-pcre` crate is
  split out.

## Verification

- `cargo deny check` accepts the crate graph.
- Oracle cases in `contracts/vm/cases.jsonl` for `preg_match` and `preg_replace` match the lab PHP 8.5
  CLI (`cargo xtask lab vm`).
- Roadmap step 19 records the bound `preg_*` subset.
